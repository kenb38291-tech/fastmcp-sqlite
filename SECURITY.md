# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a vulnerability

The FastMCP SQLite development team takes the security of our software seriously. If you discover a vulnerability, please do NOT disclose it publicly on GitHub issues.

Instead, please report security issues through GitHub's [Private Vulnerability Reporting](https://github.com/kenb38291-tech/fastmcp-sqlite/security/advisories/new).

Please include:
- A clear description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a minimal reproducible example.
- Details of the operating system and Python version tested.

We will acknowledge receipt within 48 hours and work with you to release a coordinated security patch.
